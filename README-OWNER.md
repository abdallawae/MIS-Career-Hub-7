# MIS Career Hub — Owner Edition Phase 3

تم تطوير النسخة لتشمل: 12 مسارًا × 10 مستويات × 6 دروس = 720 صفحة درس فعلية، صفحات مسارات، بحث، تتبع تقدم محلي، Owner Dashboard مبدئي، وملف Supabase schema.

## التشغيل
- ارفع المجلد إلى GitHub Pages.
- عند استخدام Supabase: أنشئ `supabase/config.js` من المثال وضع Publishable/anon key فقط.
- شغّل `supabase/schema.sql` في SQL Editor.
- فعّل Google/Facebook/Phone OTP من إعدادات Supabase.
- اجعل حسابك Admin بعد أول تسجيل دخول.

## مهم
لا تضع service_role أو أي Secret Key في الموقع أو GitHub.
